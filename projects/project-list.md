## 二、实战应用项目

### 2. LLM API Test

- **项目仓库：** [llm-api-test](https://github.com/kaiyuegong1-stack/llm-api-test)
- **学习阶段：** HTTP / API / JSON / Python 自动化测试
- **主要内容：**
  - 使用 requests 调用大模型 API
  - API Key 认证异常测试
  - 模型参数与请求异常测试
  - 响应时间统计
  - 使用 pytest 编写自动化测试
  - 生成 HTML 测试报告
- **项目目标：** 熟悉大模型 API 调用流程，掌握基础接口测试与自动化测试方法。
